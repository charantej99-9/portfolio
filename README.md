# My Portfolio

## How to change things
- **Text, projects, skills, links:** open `data.js` and edit. Save with Ctrl + S.
- **Your photo:** put a square-ish photo at `images/profile.jpg` (replace the file if it exists).
- **Resume:** replace `resume.pdf` with your latest one (keep the same name).
- **Colors:** open `style.css`, edit the values at the very top (`--accent`, `--accent2`, ...).

## Run on your computer
Install the VS Code extension **Live Server**, right-click `index.html`, choose **Open with Live Server**.

## Put it live
```
git add .
git commit -m "update portfolio"
git push
```
(Details: GitHub repo → Settings → Pages → Branch: main → Save.)
